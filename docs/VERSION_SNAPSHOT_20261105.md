## 本快照收录

1. `metasoclitk`、`metasocli-video-prompts`、`metasocli-video-prompts-旁白` 新配方按 character/scene/prop 追加用户对应去噪原文。完整正文保持，批量本地组装和校验后再计算哈希；旧图片和冻结计划继续按原记录复用、恢复。
2. 三份去噪文本的 Git 属性明确为 `-text`，防止 Windows 自动换行转换改变字节并使包内 SHA-256 校验失败。
3. 图片 `images prepare` 支持明确的后继计划 `restartOf`，保留原未知请求和原准备记录；已有有效素材可按准确文件复用。
4. 图片等待保持默认600秒，可按显式配置延长至1200秒；新计划的 `generationTimeoutMode: "exact"` 支持精确300秒，缺省仍兼容原300→600秒行为。创建请求和响应体使用一致有效时限，不自动重发未知请求。
5. 已明确关联且以用户来源登记的同一结果，在无关段落引用变化时可完成原图片任务的本地恢复收尾；实际图片依赖、身份及哈希检查保留。
6. 三个入口及共用工作流引用已有图片授权说明，减少对同一已授权事项的重复确认；宿主审批和一次性重试边界保留。
