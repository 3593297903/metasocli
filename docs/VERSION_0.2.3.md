# metasocli 0.2.3

2026-11-28。基于 `v0.2.2`（`e7d6fb6`）。本版让 `$metasocli`、`$metasoclitk` 和 `$yiciyuang2.5cli` 在新图的第一次生成请求中按素材类型加入去噪要求。Git 标签为 `v0.2.3`。

## 生图提示词的变化

| 素材 | 本版的变化 |
| --- | --- |
| 人物 | 三个入口的五视图首稿都写入去噪要求，抑制随机噪点、彩色噪波和锐化白边，保留人物的皮肤特征、发丝和织物纹理。沿用白底五视图，上排正、侧两张脸，下排正面和侧面到短颈，右下背面保留后脑。 |
| 场景 | `$metasocli` 和 `$yiciyuang2.5cli` 现在与 `$metasoclitk` 共用已有的场景去噪全文。墙面、天空和阴影减少随机颗粒，木纹、石材结构和设定中的旧化痕迹予以保留。 |
| 道具 | 同样为前述两个入口启用已有的道具去噪全文。重点抑制表面杂色、假划痕和过度锐化，保留接缝、刻度、刻纹及指定的磨损。 |
| 首帧 | 三个入口的单幅首帧提示词都加入去噪句，抑制暗部彩噪与压缩伪影，保留分镜指定的景深、雨雾和颗粒风格。 |

生图前保存完整提示词及其哈希。纯提示词与带参考图的请求都使用这份文字，每张图只需一次生成。复用已有素材或恢复旧任务时继续使用原记录。[配方规则](../skills/metasocli-reference-images/references/denoise-policy.md)
