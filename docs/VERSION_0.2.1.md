# metasocli 0.2.1

2026-11-27。本版在 `v0.2.0`（`f4153c31c63d63c4ead8b2a470dbc5d31ad04d3c`）上加入创艺坊 Seedance 2.5 视频生成。包和 CLI 的版本号为 `0.2.1`，可通过 Git 标签 `v0.2.1` 定位本版源码。

## 准备与生成

| 技能入口 | 用途 |
| --- | --- |
| `$yiciyuang2.5cli` | 准备分镜、有序参考素材和逐集清单。单段 5–30 秒，最多 30 张参考图、10 条参考音频和 10 段参考视频。 |
| `$ycy480sd2.5` | 按指定集段调用 `seedance-2.5-face-full-5s-480p`。 |
| `$ycy720sd2.5` | 按指定集段调用 `seedance-2.5-face-full-5s-720p`。 |

执行入口检查提示词和素材顺序，保存创建意图和平台任务号，按原任务号查询并下载 MP4。等待达到 40 分钟时记下进度并继续查询。混用两个平台的故事按本次选中的分镜校验。[输入格式](INPUT_FORMAT.md) · [提交、续收和一次性重试](SEEDANCE_SKILL.md)

升级后重选已知旧单时会核对冻结的原稿和素材。旧版把对白中的“参考图1”替换成“@图1”而造成请求哈希变化的情况下，程序可找到原操作。明确授权修正重试后，原操作与子操作分别保存，能分别查看实际发送内容和结果。

## 已知限制

- 视频返回后会做本地解码和文件检查。时长判断使用 MP4 标注的总时长，可能把音轨足长、画面提前结束的文件交付为完成。本版没有自动比对成片人物、动作或台词。
- 平台的 422 错误会保留原因和可识别的素材位置。错误文字只提到某份素材已通过时，客户端仍可能误将它标为出错文件。
- 部分旧稿只在普通文字中使用“参考图1”，缺少显式图号或绑定行。普通重选和按原批次重试可能被图号校验挡住，原操作仍可查询。准备清单按整集输出，视频入口支持按段选择。
- Metaso H3 在强制中断时可能留下空的协调锁，同一运行目录中的其他 H3 故事也可能遇到 `LOCK_UNKNOWN`。
