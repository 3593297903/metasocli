# metasocli 0.2.2

2026-11-28。基于 `v0.2.1`（`dbf5881`）。本版更新了人物五视图首稿和创艺坊图片模型，Git 标签为 `v0.2.2`。

## 人物五视图

`$metasocli`、`$metasoclitk` 和 `$yiciyuang2.5cli` 为新人物写第一份生图提示词时，共用一份 1536 × 2048、3:4 竖幅白底模板。上排为正面和朝画面右的左侧 90° 头肩像。下排正面和侧面都从短颈平顶画到鞋底，右下背面保留完整后脑。三个着装视图使用相同身量，肩线、髋线和鞋底线分别对齐。[人物首稿模板](../skills/metasocli-reference-images/references/portrait-layout.md)

普通人物首稿直接使用剧本文字。填写人物、后脑、衣装、正面所见、侧面所见、背面所见和画风七项后，将完整提示词随请求提交。用户指定图片作为实际输入时，按配方中的用途和顺序附图。

## 创艺坊图片请求与恢复

新建图片计划默认使用 `gpt-image-2.6-sunburst`。纯文本请求走 `/v1/images/generations`，带指定参考图的请求走 `/v1/images/edits`。已冻结的 `gpt-image-2.5` 任务按原计划模型和提示词恢复，下载与登记会核对请求对应的回执。[图片 API 用法](IMAGE_API_USAGE.md)

## 验证记录

用渡船驾驶员、制琴师和绘图员三份资料回填模板，所得提示词与此前发往创艺坊的原文逐字一致。三次实单的回执均记录图片输入 token 为 0，返回的 PNG 均为 1536 × 2048。三张首稿均满足下排仅背面保留头部的要求，制琴师背影的肩线略低于另外两个视图。
