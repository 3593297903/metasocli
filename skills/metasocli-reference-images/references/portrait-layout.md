# 竖幅人物五视图的首稿构图

用于同一人物同一造型的 3:4 白底竖幅首稿。普通新人物直接用剧本文字填好下面两段正文，用一个换行依次相接，作为第一次生图的完整提示词。按当前入口的人物说明填写七处双花括号，发送前确认每一处都已替换为当前人物的资料。

## 开篇先定整页

“人物”填姓名、身份、年龄感、身形、五官、发型和神情。整页布局先于这些人物细节。

```text
在一张纯白画布上将五个视图排为上面两幅、下面三幅。下排左、中两格的短颈平顶上方连续留白，右格保留完整后脑。为{{人物}}设计一张 3:4 竖幅白底角色设定图，1536×2048。上排是两幅真人头肩照。下排从左到右实际摆放的是：无头正面着装人台、无头侧面着装人台、穿同一套衣服的有头真人背影。两具服装人台都有本人的肤色短颈、真实手和穿鞋的双脚。

构图固定为上排两幅头肩特写，下排两幅从颈部以下开始的穿着视图，加一幅完整背影。整页只有两张脸和三个头部轮廓，第三个头部轮廓是右下的后脑。左下和中下是仅展示衣装的无头穿着视图。
上排占约三分之一。左上真人正面，双眼正视镜头。右上真人严格左侧90°，鼻尖指向画面右。两个发顶与下巴完整入画。
```

## 下排先定短颈，再写服装

“后脑”填从背后看得到的发型与轮廓。“衣装”填整套穿着、鞋履、配饰和手持状态。“正面”和“侧面”分别填短颈以下该角度可见的衣装、双手、物件和鞋子。“背面”填后发、衣背结构与鞋跟等背后可见的细节。“画风”沿用当前故事与入口指定的美术风格。

```text
下排约占三分之二，左格和中格是无头穿着视图，等高的短颈平顶直接结束在下巴原本所在的位置，只画短颈、身体、手和双脚。左、中格颈顶上方留一块完整的纯白空间，没有脸、头、耳、头形或额外头像。
左下人台面向镜头，中下人台严格侧向画面右。两个人台的上端都是衣领以上的一小截肤色短颈，最高处为平直、连续的肤色封顶，中央与两端等高。保留左、中两列从下排上缘到两个短颈顶的整条白色留空。侧身的背、鞋跟在左，前襟、鞋尖在右。
右下站着这个真人，背对镜头，从完整的{{后脑}}、后颈、肩背到鞋跟连成一个人形。下排右侧的发顶高出左、中两截颈顶约一个头。下排三者身量同尺度、肩线髋线鞋底线分别齐平，脚下不设展示支架。

衣装为{{衣装}}。左下可见{{正面}}。中下可见{{侧面}}。右下可见{{背面}}。
上排两张脸与右下后脑属于同一个角色。柔和均匀棚灯，自然肤色。画风为{{画风}}。无缝纯白背景，画面不印任何名称、编号、边框或格线。
```

原文指定坐姿、轮椅或特殊形体时，按实际姿态调整对应的肢体、鞋底和支撑描述。用户指定逐字入画的文字时，将最后一句的画内文字要求改为该原文。用户明确提供的逐字提示词以当次要求为准。

## 有用户指定的参考图时

仅作排版讨论的样图通过上述文字体现。用户明确指定某张图作为本次生图输入时，在第一份实际提示词开头，按文件的真实输入顺序交代每张图的用途。排版图指定五格摆位、朝向、两处短颈留白和人体比例。身份图指定当前人物的五官、发型、身形。服装图指定这套衣装和配饰。同一张图确实兼有多项用途时一次列清即可。

仅供排版的样图里如果有容易串入的服装或手持物，在人物设定中逐项写清当前角色的领口、外套轮廓、道具和握持的手。只采用当前故事已经确定的差异。将用户指定的参考图登记为素材，在新人物配方的图片依赖里列出真实文件。提交前核对其 ID、哈希与顺序。分镜按原设计引用本人物成图。
