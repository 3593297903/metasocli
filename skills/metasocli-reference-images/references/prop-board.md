# Prop design boards

Read only for `prop` assets.

## Purpose

Lock the declared story-relevant object's shape, scale, material, color, wear, markings, movable parts, and narrative use. Preserve upstream asset identities. A board may explain the supplied wearing, operation, state transition, or ownership relationship using labeled panels; showing those relationships does not create new assets or authorize inventing additional story states.

## Default composition

Create a horizontal 16:9 professional “影视道具结构与材质设计板”:

- the actual story prop's title and one large three-quarter hero view;
- front, side, back, and top/bottom orthographic views when relevant;
- three to six close detail panels for fasteners, texture, wear, mechanism, contents, or story evidence;
- a restrained material/color swatch area;
- a scale diagram using only supplied measurements or a neutral non-numeric scale cue;
- neutral light or dark matte board background with precise dividers and clear title, label, and explanatory text hierarchy;
- wearing/operation views, relevant before-and-after states, arrows, and ownership notes when the current script, user request, and board type require them.

Use hands, wearing context, or operators where they explain the declared prop's use; for a static object, a still-life board remains suitable. Choose content from this story rather than imposing a universal no-hands or no-state-demonstration rule. Identity-defining contents follow the requested facts. A reference board supplies its declared layout/style role, not sample identities, measurements, props, or story text.

## Prompt content

Restate the exact object category, dimensions when known, construction, materials, colors, surface finish, wear, age, labels, content, mechanical states, ownership, and continuity requirements. Keep construction and identity stable across views. Label supplied state changes and operation directions distinctly when relevant; do not invent extra states or silently change asset allocations.

Use `exactText` verbatim when the user explicitly requires particular wording. Organize the board title, view labels, material notes, supplied dimensions, and state explanation naturally from the known object facts; an empty list does not prohibit this copy. Distinguish presentation labels from actual object markings and story evidence.

## Presentation

Present the object and any applicable wearing, operation, or state relationship with consistent construction, material, scale, and wear across all views. Use physically credible perspective and mechanisms, realistic surface detail, and the restrained production-board layout. Include the actual title, structural/material notes, view labels, and relevant state/ownership explanations in the full prompt, not just “follow the template”.
