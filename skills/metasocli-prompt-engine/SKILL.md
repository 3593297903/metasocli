# H3 剧本分段

读取全部剧本和 [草稿契约](../../docs/INPUT_FORMAT.md)。本技能只产出本地内容草稿，不调用视频 API。

- 每个生成段 4–15 秒，使用显式整数时长；考虑完整台词的实际可讲述时间，台词过长时增加生成段，不加速、摘要或丢句。
- 镜头是段内的描述单位。段落来源范围必须完整、连续、按原顺序覆盖规范文本。`prompt` 可在完整来源原文前后增补摄影、动作、声音说明；必须原样包含该段原文，保留说话人和标点。
- 为人物造型、场景状态、关键道具和首帧建立独立配方。assetId 用小写字母、数字、下划线及短横线，不用路径。记录完整图片配方、必要精确文字、有序依赖；普通外观补充明确标为生成设定，不冒充原文事实。
- `references` 数组就是请求图序。参考图最多 9 张；首帧恰好 1 张且不能混合参考图。尾帧、视频参考、音频参考本版未开放。
- 用本地 `{{ref:assetId}}` 指示确切引用，不要按姓名做全局替换。H3 请求固定 MiniMax-H3，768P 或 2K；不能带入旧模型的 480p、节点标记或其他执行开关。
- 保存完整草稿，再执行 CLI import 和 plan 验证。程序校验不代替对叙事与时长的人工判断；不要宣称通过校验就保证模型逐字还原台词。
