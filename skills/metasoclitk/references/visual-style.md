# 统一视觉规则：jianc 设计板

本规则适用于本入口新准备的人物、场景、道具资产。先完整阅读当前故事，再填写本技能同目录的类型模板；三类配方的视觉组织完全使用这套新规则，不混入共用图片技能的旧类型模板。它定义通用目标审美，不定义某部故事的角色与世界观。

## 统一审美

采用半写实奇幻CG电影美术风格：可信的实体比例、透视、重量、接触关系与光照，清楚而精致的造型，细腻而可辨的真实材料。人物具有真人皮肤质感、清楚眼部结构和适龄骨相，五官可适度美型化；场景与道具使用同一材质和光照语言。

“奇幻CG”描述渲染审美，不意味着为写实故事新增魔法、发光、神装或建筑。只有本故事已确定的能量、奇幻生物和非常规空间才表现对应效果。时代、地域、身份、服装和物件归属均从当前输入确定。各资产在同一美术体系中保留自己的颜色与材料，不全部染成金色或银色。

人物背景为浅中性灰或白色无缝背景。场景板采用黑色哑光底；道具板采用深中性灰哑光底；后二者使用细金分隔线、金色标题和浅灰正文。板底和排版颜色不改变主体材质。

三类资产默认目标 `1920×1088` 横板，约16:9；这是提示词和API计划的目标尺寸，实际文件尺寸仍由原技术检查获得。不得写成精确16:9、2K或4K。用户明确要求其他支持规格时保留所选布局并适配尺寸。

## 身份事实与生成补足

- 一个固定人物造型、一个地点状态、一件道具或明确组合各自保持独立资产身份。不是每段都新画一份，也不将全体人物拼成一个人物资产。
- `sourceFacts` 只记原文、用户提供资料或已核对参考图中的确定事实。生成时需要决定的普通外观在 `visualDescription` 中标为生成设定，随后跨段保持一致；不冒充原片证据，不随下一集重新随机决定。
- 不凭空填写精确年龄、身高、体重、测量尺寸、品牌、身份排行、剧情铭文或内部机制。不确定的身份对应关系保留待确认，继续其他独立项。
- 对没有显示的背面、连接和空间平面，用满足已知结构的保守制作设计补足，并在适用资料中注明“制作补足”或“制作示意”。不因此增添隐藏房间、剧情机关或新事件。
- 资料区实际填本故事内容。`exactText: []` 仍保留正常标题、视图标签、材质及状态说明；用户要求逐字保留的文案放入原 `exactText`。

## 参考图的作用

无用户指定参考时，可依据完整文字配方生成，不要求为套模板先获取 jianc 原图。

有参考时，明确每张图的用途并保留原依赖顺序：当前造型参考锁定服装与状态；身份参考锁定脸、年龄感和身体；风格参考只约束材质、光照和画面审美；布局参考只约束排版。风格或布局示例不提供本故事的姓名、脸、衣服或道具。使用同一个人另一套服装的身份图时，写明仅沿用身份，服装以本条为准。

要实际使用的参考文件按原图片契约正式登记为依赖，不只在文字中写“参照图片”却不传文件。无需使用的原片截图可仅作为来源记录，不能为了记录来源而增加每张API请求的输入依赖。纯文字不能保证与原片完全同脸；已确认的身份图可供后续造型实际引用。

## 配方传递与结果

将当前故事事实和本技能完整板式展开成最终提示词，先落盘、计算哈希、校验并import，再按原后端提交；不得在提交时另缩写或二次改写。所有方括号槽位填好或按不适用省略，不能把未填模板或一份多人资料表当作最终配方。

沿用共用技能的首次结果交付与技术验证。jianc旧六图曾在用户要求下作比较和局部修正，这不成为本入口自动检查、自动重画或追加付费调用的步骤。用户要求修订特定图片时，按原项目正式修订及授权范围处理。
